# Vetturino — Italy Chauffeur Service Website

A premium, SEO-focused website for a private chauffeur service operating across Italy. Built with
Next.js (App Router), TypeScript and Tailwind CSS, with a data-driven architecture so destination,
airport and route pages can scale to hundreds of entries without restructuring the site.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build   # production build
npm run start   # serve the production build
npm run lint    # ESLint
```

## Content & Data

All site content lives in `lib/data/` as typed TypeScript arrays — there is no CMS or database.
Each dynamic route (`/destinations/[slug]`, `/airport-transfers/[slug]`, `/routes/[slug]`) is
statically generated from these files via `generateStaticParams`.

| File | Powers |
| --- | --- |
| `lib/data/destinations.ts` | `/destinations` and `/destinations/[slug]` |
| `lib/data/airports.ts` | `/airport-transfers` and `/airport-transfers/[slug]` |
| `lib/data/routes.ts` | `/routes` and `/routes/[slug]` |
| `lib/data/services.ts` | `/chauffeur-service`, `/hourly-chauffeur`, etc. |
| `lib/data/fleet.ts` | `/fleet` |
| `lib/data/tours.ts` | Private tours section |
| `lib/data/faqs.ts` | Sitewide FAQ content + FAQ schema |
| `lib/data/testimonials.ts` | **Placeholder reviews** — replace before launch |
| `lib/siteConfig.ts` | Brand name, contact details, domain — all placeholders to confirm |

### Adding a new destination, airport or route

Add a new object to the relevant array in `lib/data/`. The page, metadata, sitemap entry and
internal links are generated automatically — no new files required.

## Before Launch — Placeholders to Replace

This build intentionally avoids fabricating company facts. Search the codebase for `[` bracketed
placeholders and the following before going live:

- `lib/siteConfig.ts` — real domain, phone number, email, legal entity name, office address
- `lib/data/testimonials.ts` — real, verified customer reviews
- `components/ui/QuoteForm.tsx` — connect the form submit handler to your booking/CRM system
- Cancellation, delay and child-seat policies referenced in FAQ copy
- Replace `ImageBlock` placeholder visuals with licensed photography throughout `components/`
- `public/images/` — add real fleet, destination and airport imagery (referenced paths already exist in the data files)
- `app/privacy-policy/page.tsx` and `app/terms-conditions/page.tsx` — **template legal text only**; have a qualified professional review both before launch, especially GDPR obligations, cancellation terms and liability language
- `components/layout/CookieNotice.tsx` — currently a simple essential-cookies notice; upgrade to a full consent-management flow if you add analytics or marketing cookies

## SEO

- `app/sitemap.ts` and `app/robots.ts` generate `/sitemap.xml` and `/robots.txt` from the data files
- Organization, WebSite and Service JSON-LD in `app/layout.tsx` and `components/templates/ServicePageTemplate.tsx`
- FAQ schema generated automatically by `components/sections/FaqSection.tsx`
- BreadcrumbList schema generated by `components/ui/Breadcrumbs.tsx`
- Per-page metadata (title, description, canonical) via each route's `generateMetadata`/`metadata` export
